# سَحاتِك — دليل تشغيل الموقع

الموقع ثابت (Static) بالكامل: ملفات HTML جاهزة، بدون قاعدة بيانات ولا لوحة تحكم.
هذا يجعله سريعاً جداً وآمناً وتقدر ترفعه على أي استضافة.

## المتطلبات
Python 3.8 أو أحدث فقط. لا توجد مكتبات إضافية.
على ويندوز: نزّل Python من python.org وفعّل خيار **Add Python to PATH** أثناء التثبيت.
(إذا لم يعمل الأمر `python` على ويندوز، استخدم `py` بدلاً منه.)

## الأوامر (من داخل مجلد WebSite)
| الأمر | ماذا يفعل |
|---|---|
| `python build.py new my-post-slug` | ينشئ ملف منشور جديد جاهز للكتابة في `content/posts/` |
| `python build.py serve` | يبني الموقع ويفتحه للمعاينة على http://localhost:8000 |
| `python build.py` | يبني الموقع النهائي بكل اللغات في مجلد `public/` |
| `python build.py status` | يعرض المنشورات التي تنقصها ترجمة |

## نشر منشور جديد (4 خطوات)
1. `python build.py new facebook-scam-2` ← يُنشأ ملف باسم التاريخ والـ slug.
2. افتح الملف واكتب: العنوان، التصنيف، النوع، الملخص، ثم المحتوى.
3. غيّر `draft: true` إلى `draft: false`.
4. `python build.py` ثم ارفع **محتوى** مجلد `public/` إلى الاستضافة (public_html).

## اللغات
الموقع بسبع لغات. العربية هي الأساسية على الرابط الرئيسي، وكل لغة لها مسار خاص:

| اللغة | الرابط |
|---|---|
| العربية | `sahati-tech.com.ly/` |
| English | `sahati-tech.com.ly/en/` |
| Türkçe | `sahati-tech.com.ly/tr/` |
| Русский | `sahati-tech.com.ly/ru/` |
| Español | `sahati-tech.com.ly/es/` |
| Filipino | `sahati-tech.com.ly/fil/` |
| 中文 (简体) | `sahati-tech.com.ly/zh/` |

- **نصوص الواجهة** (القوائم، الأزرار، العناوين، أسماء التصنيفات) كلها في `content/i18n/strings.json`.
- **القاموس** لكل لغة في `content/i18n/<lang>/glossary.txt`.
- **ترجمة المنشور** ملف بنفس اسم الملف العربي داخل `content/i18n/<lang>/posts/`.
  فيه فقط: العنوان والملخص والنص (والخطوات للنصائح، ونص القاعدة للقواعد).
  التاريخ والنوع والتصنيف والغلاف تُؤخذ تلقائياً من الملف العربي.
- عند `python build.py new ...` تُنشأ ملفات الترجمة الفارغة لكل اللغات تلقائياً.
- المنشور الذي لم يُترجم إلى لغة ما لا يظهر في تلك اللغة فقط، ويبقى ظاهراً في باقي اللغات.
- كل صفحة تحمل وسوم `hreflang` حتى تعرض محركات البحث للزائر النسخة المناسبة للغته.
- أسماء القوائم داخل التطبيقات (فيسبوك، واتساب، آيفون) مكتوبة كما تظهر في واجهة كل لغة. راجعها إذا تغيّرت التطبيقات.

## حقول الترويسة
| الحقل | القيم |
|---|---|
| `kind` | `article` مقال بغلاف · `head` شرح بدون غلاف · `tip` نصيحة سريعة (بطاقة فقط) · `quote` قاعدة (بطاقة فقط) |
| `category` | `acc` حماية الحسابات · `scam` الاحتيال · `priv` الخصوصية · `ai` الذكاء الاصطناعي · `atk` عقلية المهاجم · `biz` المؤسسات الصغيرة |
| `cover` | للمقالات: `a` داكن · `b` برونزي · `c` فاتح |
| `glyph` | نص صغير في زاوية الغلاف، مثل `2FA` أو `GPS` |
| `slug` | رابط المنشور بالإنجليزي: `sahati-tech.com.ly/posts/<slug>/` |
| `steps` | للنصائح فقط: قائمة خطوات |
| `quote` | للقواعد فقط: نص القاعدة |

التصنيفات وعنوان الموقع في ملف `site.json`. مصطلحات القاموس في `content/glossary.txt`.

## طريقة الكتابة داخل المنشور
```
## عنوان قسم          ← يظهر تلقائياً في «محتويات المقال»
### عنوان فرعي
**عريض**   *مائل*   [رابط](https://...)   `كود`   [[Ctrl]] زر لوحة مفاتيح
- نقطة            1. خطوة مرقّمة
> اقتباس
![وصف الصورة](/assets/images/photo.jpg)

:::tip عنوان اختياري      ← صندوق نصيحة داكن
:::warning               ← صندوق تحذير
:::note                  ← ملاحظة
:::action                ← صندوق «ماذا تفعل الآن؟» البرونزي (ضعه في نهاية كل مقال)
النص...
:::
```
الجداول بصيغة Markdown المعتادة (`| عمود | عمود |`).
الصور: ضعها في `static/assets/images/` واكتب مسارها `/assets/images/...`.

## النشرة البريدية
النموذج حالياً لا يرسل لأي مكان. عند اختيار خدمة (مثل Buttondown أو MailerLite أو Brevo)،
ضع رابط الاشتراك الخاص بالنموذج في `site.json` في الحقل `newsletter_endpoint` وأعد البناء.
وأضف أصل الخدمة بالتحديد (مثل `https://example-provider.com`) إلى `form-action` في ترويسة CSP داخل `vercel.json`،
فالسياسة الحالية تسمح بالإرسال إلى الموقع نفسه فقط. ما دام الحقل فارغاً يظهر النموذج معطّلاً مع عبارة «قريباً».

## ملاحظات
- المنشورات الموجودة حالياً أمثلة. احذفها أو عدّلها قبل الإطلاق.
- لا تعدّل ملفات `public/` مباشرة، فهي تُمسح وتُبنى من جديد كل مرة.
- ملف `.htaccess` (لاستضافات Apache/cPanel) يحوّل إلى HTTPS ويعرض صفحة 404 المخصصة. لا يُنسخ عند البناء على Vercel (متغير البيئة `VERCEL`) حتى لا يُنشر كملف عام.
- الصور الخارجية ممنوعة بسياسة CSP (`img-src 'self' data:`)، فاحفظ أي صورة داخل `static/assets/images/`.
- تحويل `www` إلى الدومين الأساسي مضبوط في لوحة Vercel (Settings ← Domains) وليس في `vercel.json`، حتى يكون التحويل في مكان واحد.
- المجلد `previews/` فيه نماذج التصميم القديمة للمقارنة فقط.
