Kapag tinamaan ng ransomware ang isang maliit na negosyo, hindi "Paano ito nakapasok?" ang unang tanong. Ang unang tanong ay "May malinis ba tayong backup?" Ang sagot ang magpapasya kung masamang araw lang ito o isang sakuna.

## Ang panuntunan sa isang tingin

| Numero | Kahulugan | Halimbawa |
|---|---|---|
| **3** | Tatlong kopya ng data | Ang orihinal + dalawang backup |
| **2** | Sa dalawang magkaibang uri ng storage | Drive ng computer + external drive o NAS |
| **1** | Isang kopya sa ibang lugar | Cloud service, o drive na nakatago sa ibang lugar |

## Bakit mahalaga ang kopyang nasa ibang lugar?

Hindi lang computer ang ine-encrypt ng modernong ransomware. Hinahanap nito ang bawat nakakonektang drive at bawat shared folder sa network, at ine-encrypt din ang mga iyon. Kung laging nakakonekta ang backup mo, kasing-delikado ito ng orihinal.

Kaya ang pinakamahalagang kopya ay ang hindi **maaabot** ng na-infect na computer: isang drive na dinidiskonekta pagkatapos mag-backup, o cloud service na nagtatago ng mga naunang bersyon ng mga file.

:::warning
Ang backup na hindi mo pa nasusubukang i-restore ay hindi backup. Pag-asa lang iyon.
:::

## Simpleng iskedyul para sa maliit na negosyo

- **Araw-araw:** awtomatikong backup ng mahahalagang file sa network drive.
- **Lingguhan:** kopya sa external drive na dinidiskonekta at itinatago sa ibang lugar.
- **Buwanan:** subukang i-restore ang isang random na file mula sa bawat backup.

:::action
1. Ilista ang data na kailangan ng negosyo mo para patuloy na tumakbo.
2. Alamin kung nasaan ang tatlong kopya ng bawat isa.
3. Subukan ngayon na i-restore ang isang file mula sa backup mo.
:::
