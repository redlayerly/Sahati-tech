why = 本图谱后面的一切，从 ChatGPT 到 AI 智能体，都建立在这些思想之上。理解了基础，你就能明白模型为什么有时会出错，以及为什么劣质数据会造出劣质模型。
example = 邮箱的垃圾邮件过滤器。没人为每一封诈骗邮件写规则，系统是从数百万封已标注的邮件中学会了垃圾邮件长什么样。

[pkg 00]
name = 数学基石
desc = 理解算法内部运作的基础。没有它，就无法读懂研究论文，也无法理解模型的训练过程。
simple = 计算机看不到图片或句子，它看到的是排成表格（矩阵）的数字。线性代数决定这些数字如何存储和相乘，微积分告诉我们该往哪个方向调整它们才能减小误差，概率论则让模型能说出"我有 90% 的把握"，而不只是简单的是或否。
analogy = 梯度下降就像在浓雾中下山：你看不见山谷，但能感觉到脚下的坡度，于是每一步都朝最陡的下坡方向走，直到到达最低点。
example = 地图应用估算你的到达时间时，是根据历史数据统计计算出拥堵的概率，而不是套用一条固定规则。

[term 00.4]

[term 00.5]
name = 梯度下降

[pkg 01]
name = 机器学习基础
desc = 让计算机从数据中提取规律并自主学习，而无需逐步编写每条指令的方法。
simple = 在传统编程中，我们写好规则、输入数据、得到结果。在机器学习中，我们输入数据和正确答案，由模型自己推导出规则。最大的风险是它死记硬背训练样本而没有学到真正的规律，遇到新情况就会失败。
analogy = 只背往年考题答案的学生，只能在那几套试卷上及格，题目一变就不及格。这就是过拟合。所以我们会预留一部分数据（测试集），用模型从未见过的题目来考它。
example = 银行用在数百万笔标注为"正常"或"欺诈"的交易上训练出的模型来识别可疑交易。这就是监督学习。

name = 人工智能

[term 01.1]
name = 机器学习

[term 01.2]
name = 监督学习
def = 模型从带有正确标签的样本中学习输入与输出之间映射关系的训练范式。

[term 01.3]
name = 无监督学习
def = 在没有预设标签的数据中发现隐藏结构、聚类和潜在表示。

[term 01.4]
name = 强化学习
def = 以目标为导向的学习方式：智能体在环境中采取行动，以最大化累计奖励。

[term 01.5]
name = 数据集
def = 用于训练、验证和测试模型的结构化或非结构化数据的有序集合。

[term 01.6]
name = 特征
def = 从原始输入数据中提取、供模型做决策的可度量变量和预测属性。

[term 01.7]
name = 标签
def = 监督模型要学会预测的正确答案或类别。

[term 01.8]
name = 训练集
def = 数据集中直接用于调整模型内部参数的主要部分。

[term 01.9]
name = 验证集
def = 训练过程中用于调节超参数、及早发现过拟合的独立数据子集。

[term 01.10]
name = 测试集
def = 开发期间完全未让模型见过、专门留作公正评估最终性能的数据。

[term 01.11]
name = 损失函数
def = 衡量模型对单个样本的预测与正确答案之间差距的数学函数。

[term 01.12]
name = 代价函数
def = 对整个批次或整个数据集的损失取平均得到的整体误差指标。

[term 01.13]
name = 学习率
def = 决定每次优化时参数更新步长大小的超参数。

[term 01.14]
name = 过拟合
def = 模型记住了训练数据中的噪声和细节，导致无法泛化到新数据的状态。

[term 01.15]
name = 欠拟合
def = 模型过于简单，无法捕捉训练数据中的基本规律和关系。

[term 01.16]
name = 偏差
def = 源于学习算法过于僵化的假设的系统性误差，常导致欠拟合。

[term 01.17]
name = 方差
def = 模型预测对训练集中随机噪声和特殊细节的敏感程度，常导致过拟合。

[term 01.18]
name = 正则化
def = 在训练中加入的数学惩罚项（L1/L2、Dropout），用于限制模型复杂度、防止死记硬背。

[term 01.19]
name = 交叉验证
def = 把数据分成多份、轮流用作训练和验证的重采样方法，以获得稳健的评估结果。

[term 01.20]
name = 特征工程
def = 把原始变量转换为信息量更高的表示，以最大化算法效果的方法与技巧。

[term 01.21]
name = 模型泛化
def = 衡量 AI 系统的根本标准：在从未见过的新数据上依然保持准确和可靠。

[pkg 02]
name = 深度学习
desc = 多层神经网络架构，能够自动从复杂数据中学习越来越深层的表示。
simple = 神经网络由多层简单的数字"神经元"组成。每一层接收上一层的输出，并提取更深一层的规律：在一张图片里，第一层识别边缘，下一层识别形状，更深的层识别人脸。网络出错时，误差会从后往前传回（反向传播），每一层都对自己的权重做细微调整。
analogy = 就像一条流水线：每个工人加上一点小工序。出了次品时，质检员沿着流水线往回走，告诉每个人他对这个缺陷负有多大责任，让他改进自己的做法。
example = 手机的人脸解锁使用卷积神经网络（CNN），把你的脸变成一组数字"指纹"，再与存储的那组进行比对。

[term 02.0]
name = 人工神经网络
def = 受生物神经元启发、由相互连接的节点组成并按层依次排列的计算图。

[term 02.1]
name = 感知机
def = 神经网络最基本的单元：对输入做线性组合，再经过激活阈值输出。

[term 02.2]
name = 多层感知机
def = 含有隐藏层的前馈网络，能够拟合任意复杂的非线性函数。

[term 02.3]
name = 前向传播
def = 输入数据依次流经网络各层与激活函数、计算出最终输出的过程。

[term 02.4]
name = 反向传播
def = 从输出端往回计算、利用链式法则求出损失对每个参数梯度的高效算法。

[term 02.5]
name = 激活函数
def = 作用于神经元加权和的非线性变换，使神经网络能够学习非线性规律。

[term 02.6]
name = ReLU
def = 修正线性单元；输出 max(0, x)，可缓解梯度消失问题且计算速度快。

[term 02.7]
name = Sigmoid
def = 把任意实数映射到 [0, 1] 区间的 S 形函数，常用于二分类的概率输出。

[term 02.8]
name = Tanh
def = 双曲正切函数；把输入映射到 [-1, 1]，输出以零为中心，有助于梯度下降更平衡。

[term 02.9]
name = GELU
def = 高斯误差线性单元；BERT、GPT 等现代 Transformer 中的标准概率型激活函数。

[term 02.10]
name = 批归一化
def = 对每个小批次的激活值做归一化，以稳定训练并加速收敛的技术。

[term dropout]
name = Dropout（随机失活）
def = 训练时随机关闭一部分神经元，使网络无法依赖任何单个神经元，从而学到更通用的规律而不是死记硬背。

[term weight-init]
name = 权重初始化
def = 在训练开始前为网络权重选择初始值。初始值不好，可能让训练极其缓慢，甚至完全无法推进。

[term lr-scheduler]
name = 学习率调度器
def = 在训练过程中调整学习率，通常一开始迈大步，接近尾声时改为小而精准的步子。

[term transfer-learning]
name = 迁移学习
def = 把在大型任务上训练好的模型作为新任务的起点，从而大幅减少所需的数据和时间。

[term optimizers]
name = 优化器：SGD、Adam、AdamW
def = 在算出误差后决定如何调整权重的方法。SGD 最简单；Adam 会自动为每个权重调整步长；其变体 AdamW 是如今训练语言模型最常用的选择。

[term batch]
name = 批次（Batch）
def = 模型在每次更新权重前一起处理的一小组样本，而不是逐个处理或一次处理全部数据。

[term epoch]
name = 轮次（Epoch）
def = 模型完整地过一遍整个训练集。训练通常会进行多个轮次。

[term cnn]
name = CNN（卷积神经网络）
def = 专为图像设计的网络，用一个小窗口在图像上滑动，识别边缘、形状和图案。它推动了计算机视觉的革命。

[term rnn]
name = RNN（循环神经网络）
def = 逐步处理序列、同时携带对前文"记忆"的网络。在 Transformer 出现之前被用于文本和语音。

[term lstm]
name = LSTM（长短期记忆网络）
def = 一种带有"门"的循环网络，由门决定保留什么、遗忘什么，因此能记住长序列开头的信息。

[term gru]
name = GRU（门控循环单元）
def = LSTM 的简化、更快版本，门更少，在许多任务上表现相近。

[term autoencoder]
name = 自编码器
def = 一种学习把数据压缩成小型表示、再将其重建的网络。可用于发现异常，例如某笔交易因为不寻常而无法被模型很好地重建。

[pkg 03]
name = 开发框架与工具链
desc = 用于构建、分发和微调大型基础模型的软件生态与工具库。
simple = 如今几乎没有人从零开始写神经网络。PyTorch 等库负责在显卡上完成繁重的计算，Hugging Face 等平台托管着数以千计的现成模型。LoRA 等技术让你只需训练极小的一部分参数，就能把一个庞大的模型适配到自己的任务上。
analogy = LoRA 就像给一本厚书加一个小小的附录，而不是把整本书重新印刷。原书保持不变，你的修改都在附录里。
example = 一家想要模型听懂粤语口语的初创公司，不必花数百万美元从头训练。它可以拿一个开源模型，在一台机器上用 QLoRA 进行微调。

[pkg 04]
name = AI数据工程
desc = 管理数据采集、清洗、特征管理与质量控制的流水线和架构。
simple = 模型永远不会比它学习的数据更好。因此 AI 领域大量实际工作是：收集数据、清除重复和错误、标注正确答案，并记录数据版本，以便准确知道每个模型是用什么训练的。
analogy = 再好的厨师也做不出好菜，如果食材是坏的。数据工程就是开火之前的采购、清洗和切配。
example = 只用一家医院的 X 光片训练的医疗模型，到了另一家医院可能失灵，因为两家的成像设备不同。问题出在数据上，而不是算法。

[term 04.5]

[term 04.11]

[stage s2]
title = 大语言模型 (LLMs)
lead = 生成式革命的核心：Transformer 的注意力机制、基础模型的预训练、上下文与 RAG 系统、AI 智能体，以及加速它们的推理技术。
simple = ChatGPT、Claude 这样的语言模型，本质上基于一个出奇简单的想法：预测下一个词。它们把文本切成小片段，用一种叫"注意力"的机制判断前面哪些词对当前位置重要，然后选出最可能的下一个片段。当一个巨大的模型在海量文本上训练后，这种简单的预测中会涌现出看似理解的能力：翻译、总结、写代码。
analogy = 就像句子接龙："我去面包店买了一个……"你会猜"面包"，因为你读过、听过很多类似的句子。模型做的是同一件事，只不过它读过的相当于几百万本书。
why = 这些模型已无处不在：搜索、教育、客服、编程。了解它们如何运作，你就知道什么时候可以相信一个回答、什么时候需要核实，以及它们为什么会一本正经地"幻觉"出错误信息。
example = 你打字时手机键盘推荐下一个词，那就是一个按同样原理运作的非常小的语言模型。

[si]
title = 超级智能
lead = 超级智能指的是在几乎所有领域——而不只是某一项任务——都超越最聪明人类的系统。它尚未被造出来，研究者们对它是否可能、何时可能也没有共识。我们在这里如实呈现它：一个开放的科学问题，而不是一则预言。
simple = 今天存在的所有系统，无论看起来多聪明，都被视为狭义 AI，或只在部分任务上接近通用能力。通用人工智能（AGI）是指能在人类水平上学习并完成大多数智力任务的系统。超级人工智能（ASI）则更进一步：在科学、规划和创造力上超越全人类最优秀头脑总和的系统。
analogy = 这就像三者的区别：一台只在乘法上胜过你的计算器、一位在所有科目上都胜过你的同学，以及一个胜过整所大学所有教授总和的人。第一种已经存在，第二种是研究目标，第三种还只是假说。
why = 如果真的能造出比我们更有能力的系统，关键问题就是：如何确保它的目标始终符合我们的利益并处于我们的掌控之下。这被称为"对齐问题"，也是各大 AI 实验室投入整支团队开展安全研究的原因。
example = 各国政府和组织已经在实际应对这个问题。欧盟《人工智能法案》对能力最强的通用模型施加了额外义务，政府设立的 AI 安全研究机构也会在模型发布前对其进行测试。

ladder.ASI.def = 在几乎所有领域超越人类最优秀的头脑。对于它是否可能、若可能何时实现，目前没有共识。

insight.1 = 对齐问题：系统能力越强，就越难验证它做的确实是我们想要的，而不只是看起来相似的事情。这是一个当下就在积极研究的领域，而不是留给未来的问题。
insight.2 = 各方预测差异极大。有研究者认为 AGI 可能在几年内到来；也有人认为还需要几十年，或者用现有方法根本无法实现。你读到的任何精确日期都只是观点，而不是事实。
insight.3 = 物理限制是真实存在的：训练更大的模型需要巨型数据中心、海量电力和高质量数据。这些约束决定着进步的速度。
insight.4 = 从安全角度看，能力更强的系统同时意味着更强的攻击工具和更强的防御工具。网络安全是最早感受到每一次能力跃升的领域之一。
