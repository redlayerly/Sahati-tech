example = فلتر الرسائل المزعجة في بريدك: لم يكتب أحد قاعدة لكل رسالة احتيال، بل تعلّم النظام من ملايين الرسائل المصنفة مسبقاً كيف تبدو الرسالة المزعجة.

example = البنوك تكشف المعاملات المشبوهة بنموذج تدرب على ملايين المعاملات المصنفة: «سليمة» أو «احتيال». هذا تعلم موجّه.

[pkg 02]
name = التعلم العميق
desc = الانتقال من الخوارزميات الإحصائية البسيطة إلى معمارية الشبكات العصبية الاصطناعية العميقة التي تعالج التمثيلات المعقدة.
simple = الشبكة العصبية مكونة من طبقات من «خلايا» رقمية بسيطة. كل طبقة تأخذ مخرجات التي قبلها وتستخرج منها نمطاً أعمق: الطبقة الأولى في صورة تلتقط الحواف، والتالية الأشكال، والأعمق الوجوه. وعندما تخطئ الشبكة، يرجع الخطأ من النهاية إلى البداية (الانتشار الخلفي) فتعدّل كل طبقة أوزانها قليلاً.
analogy = مثل خط إنتاج في مصنع: كل عامل يضيف لمسة صغيرة، وعندما يخرج المنتج معيباً يرجع المشرف عبر الخط ويخبر كل عامل كم ساهم في العيب ليصحح طريقته.
example = فتح الهاتف بالوجه يعتمد على شبكة عصبية التفافية (CNN) تحوّل صورة وجهك إلى بصمة رقمية وتقارنها بالمحفوظة.

[term 02.0]
name = الشبكات العصبية الاصطناعية
def = بنية حاسوبية تتألف من عقد مترابطة تحاكي الخلايا العصبية الحيوية وتنتظم في طبقات.

[term 02.1]
name = المستشعر الفردي
def = الوحدة البنائية الأبسط في الشبكة؛ تجمع المدخلات الموزونة وتمررها عبر دالة تنشيط.

[term 02.2]
name = المستشعر متعدد الطبقات
def = شبكة عصبية تضم طبقة مدخلات وطبقة مخرجات وبينهما طبقة خفية أو أكثر لحل المسائل اللاخطية.

[term 02.3]
name = الانتشار الأمامي
def = تدفق الإشارات والبيانات من طبقة المدخلات عبر العقد وصولاً لإنتاج التوقع النهائي.

[term 02.4]
name = الانتشار الخلفي
def = حساب مشتقات الخطأ بالتراجع العكسي من المخرجات إلى المدخلات لضبط الأوزان بدقة.

[term 02.5]
name = دوال التنشيط
def = معادلات تضفي اللاخطية على الشبكة، مما يتيح لها استيعاب الدوال والأنماط بالغة التعقيد.

[term 02.6]
name = دالة ريلو
def = الدالة الأكثر استخداماً؛ تبقي على القيم الموجبة وتحول كل قيمة سالبة إلى صفر لتسريع الحسابات.

[term 02.7]
name = دالة سيجمويد
def = تحول المخرجات إلى نطاق احتمالي بين صفر وواحد وتناسب مهام التصنيف الثنائي.

[term 02.8]
name = دالة الظل الزائدي
def = تحول القيم إلى نطاق ممتد بين سالب واحد وموجب واحد وتتمركز حول الصفر.

[term 02.9]
name = دالة غيلو
def = دالة تنشيط ناعمة تعتمد على التوزيع الطبيعي وتستخدم على نطاق واسع في محولات اللغة الحديثة.

[term 02.10]
name = تطبيع الدفعات
def = إعادة موازنة مخرجات كل طبقة لتقليل التشتت وتسريع استقرار التدريب في الشبكات العميقة.

[term dropout]
name = الإسقاط العشوائي
def = إطفاء نسبة عشوائية من الخلايا أثناء التدريب، فلا تعتمد الشبكة على خلية واحدة بعينها، وتتعلم أنماطاً أعم وتقل فرصة الحفظ.

[term weight-init]
name = تهيئة الأوزان
def = اختيار القيم الأولية لأوزان الشبكة قبل التدريب. التهيئة السيئة قد تجعل التدريب بطيئاً جداً أو تمنعه من التقدم أصلاً.

[term lr-scheduler]
name = جدولة معدل التعلم
def = تغيير معدل التعلم أثناء التدريب، عادة بخطوات كبيرة في البداية ثم صغيرة ودقيقة قرب النهاية.

[term transfer-learning]
name = نقل التعلم
def = أخذ نموذج تدرب على مهمة كبيرة واستخدامه نقطة بداية لمهمة جديدة، فيحتاج بيانات ووقتاً أقل بكثير.

[term optimizers]
name = خوارزميات التحسين: SGD وAdam وAdamW
def = الطرق التي تحدد كيف تُعدَّل الأوزان بعد حساب الخطأ. SGD هو الأبسط، وAdam يضبط حجم الخطوة لكل وزن تلقائياً، وAdamW نسخة منه هي الأكثر استخداماً في تدريب النماذج اللغوية اليوم.

[term batch]
name = الدفعة
def = مجموعة صغيرة من الأمثلة يعالجها النموذج معاً قبل كل تحديث للأوزان، بدل معالجة مثال واحد أو كل البيانات مرة واحدة.

[term epoch]
name = الحقبة التدريبية
def = مرور النموذج على كامل بيانات التدريب مرة واحدة. التدريب يتكون عادة من عدة حقب.

[term cnn]
name = الشبكات العصبية الالتفافية
def = شبكات مصممة للصور، تمرر «نافذة» صغيرة على الصورة لاكتشاف الحواف والأشكال والأنماط، وكانت أساس ثورة الرؤية الحاسوبية.

[term rnn]
name = الشبكات العصبية التكرارية
def = شبكات تعالج التسلسلات خطوة بخطوة وتحمل «ذاكرة» مما سبق، استُخدمت للنصوص والكلام قبل ظهور Transformer.

[term lstm]
name = الذاكرة طويلة قصيرة المدى
def = نوع من الشبكات التكرارية فيه «بوابات» تقرر ما يُحفظ وما يُنسى، فيتذكر معلومات من بداية التسلسل الطويل.

[term gru]
name = الوحدة التكرارية المبوّبة
def = نسخة أبسط وأسرع من LSTM ببوابات أقل، وأداؤها مشابه في كثير من المهام.

[term autoencoder]
name = المشفّر التلقائي
def = شبكة تتعلم ضغط البيانات إلى تمثيل صغير ثم إعادة بنائها. تُستخدم لاكتشاف الحالات الشاذة، كمعاملة لا يستطيع النموذج إعادة بنائها جيداً لأنها غير مألوفة.

[pkg 03]
name = أدوات ومكتبات التدريب
desc = المنظومة البرمجية والأدوات التي يعتمد عليها المطورون والباحثون لبناء وضبط وتدريب النماذج على مستوى الإنتاج.
simple = لا أحد يكتب الشبكات العصبية من الصفر اليوم. هناك مكتبات جاهزة مثل PyTorch تتولى الحسابات المعقدة على كروت الشاشة، ومنصات مثل Hugging Face تحتوي آلاف النماذج الجاهزة. وتقنيات مثل LoRA تسمح بتخصيص نموذج ضخم لمهمتك بتدريب جزء صغير جداً منه فقط.
analogy = LoRA تشبه إضافة ملحق صغير لكتاب ضخم بدل إعادة طباعة الكتاب كاملاً: الكتاب الأصلي يبقى كما هو، والملحق يحمل التعديلات الخاصة بك.
example = شركة ناشئة تريد نموذجاً يفهم اللهجة الليبية لا تحتاج تدريب نموذج من الصفر بملايين الدولارات؛ تأخذ نموذجاً مفتوحاً وتضبطه بـ QLoRA على جهاز واحد.

desc = إدارة ذاكرة العمل المحدودة للنموذج، وربطه بمصادرك عبر البحث والاسترجاع ليجيب من معلومات حديثة وموثوقة، مع أنظمة ذاكرة تجعله يتذكر بين المحادثات.
simple = للنموذج ذاكرة عمل محدودة اسمها «نافذة السياق»، ولا يعرف شيئاً عن وثائق شركتك أو ما حدث بعد تدريبه. الحل هو RAG: نبحث في مصادرك عن المقاطع المتعلقة بالسؤال، ونضعها أمام النموذج مع السؤال، فيجيب منها بدل أن يجيب من ذاكرته. إدارة ما يدخل هذه النافذة وما يخرج منها صارت تخصصاً اسمه «هندسة السياق».
analogy = امتحان بكتاب مفتوح: الطالب لا يحتاج حفظ كل شيء، لكنه يحتاج أن يعرف كيف يجد الصفحة الصحيحة بسرعة. البحث الدلالي هو الفهرس، والنموذج هو الطالب.
example = روبوت خدمة عملاء لشركة اتصالات يجيب عن أسعار الباقات الحالية من مستندات الشركة المحدثة، لا من معلومات قديمة تعلمها أثناء التدريب.

[term 07.0]
name = استراتيجيات تقطيع المستندات
def = تقسيم الملفات الطويلة إلى أجزاء دلالية متناسقة تضمن دقة البحث والاسترجاع.

[term 07.1]
name = الاسترجاع الدلالي الكثيف
def = البحث في المعاني والمفاهيم باستخدام متجهات التضمين بدلاً من مطابقة الكلمات الحرفية.

[term 07.2]
name = البحث الهجين المدمج
def = الجمع الذكي بين البحث النصي الحرفي (BM25) والبحث الدلالي بالمتجهات لأعلى دقة استرجاع.

[term 07.3]
name = إعادة الترتيب العصبي
def = استخدام نموذج مخصص لإعادة تقييم النتائج المسترجعة ووضع الأنسب منها في الصدارة.

[term 07.4]
name = الاسترجاع المعتمد على الرسوم البيانية
def = ربط المعرفة في شبكة من العلاقات الكيانية لتمكين النموذج من الإجابة على الأسئلة المركبة.

[term context-window]
name = نافذة السياق
def = الحد الأقصى من النص (بالوحدات الدلالية) الذي يستطيع النموذج «رؤيته» في المرة الواحدة، ويشمل الأوامر والمحادثة والمستندات والإجابة.

[term context-management]
name = إدارة السياق
def = تحديد ما يدخل نافذة السياق وما يُحذف منها مع طول المحادثة، حتى تبقى المعلومات المهمة حاضرة.

[term context-collapse]
name = انهيار السياق
def = تراجع جودة إجابات النموذج عندما تمتلئ نافذته بمعلومات كثيرة أو متضاربة، فيفقد التركيز على المهم.

[term context-compression]
name = ضغط السياق
def = تلخيص أجزاء المحادثة أو المستندات القديمة بدل حذفها، لتوفير مساحة في النافذة مع الحفاظ على المعنى.

[term context-engineering]
name = هندسة السياق
def = تصميم كل ما يُقدَّم للنموذج قبل أن يجيب: التعليمات، والمستندات المسترجعة، والذاكرة، ونتائج الأدوات، بترتيب وكمية مدروسين.

[term rag]
name = التوليد المعزز بالاسترجاع
def = البحث في مصادر خارجية عن المعلومات المتعلقة بالسؤال ووضعها أمام النموذج ليجيب منها، فتقل الهلوسة وتبقى المعلومات حديثة.

[term semantic-search]
name = البحث الدلالي
def = البحث بالمعنى لا بالكلمات المطابقة، فسؤال «كيف أسترجع حسابي» يجد مستنداً بعنوان «استعادة كلمة المرور».

[term recursive-chunking]
name = التقطيع التكراري
def = تقسيم المستند حسب بنيته الطبيعية (أقسام، ثم فقرات، ثم جمل) حتى تصل كل قطعة للحجم المناسب دون قطع الفكرة في منتصفها.

[term prompt-compression]
name = ضغط الأوامر
def = تقليص طول الأمر بحذف الكلمات غير المؤثرة مع الحفاظ على المعنى، لتقليل التكلفة وتسريع الاستجابة.

[term query-expansion]
name = توسيع الاستعلام
def = إعادة صياغة سؤال المستخدم أو إضافة مرادفات له قبل البحث، لزيادة فرصة إيجاد المستندات المناسبة.

[term contextual-retrieval]
name = الاسترجاع السياقي
def = إضافة سطر تعريفي لكل قطعة قبل فهرستها يوضح مصدرها وسياقها، فلا تفقد القطعة معناها عندما تُسترجع منفصلة.

[term parent-doc]
name = استرجاع المستند الأم
def = البحث بقطع صغيرة دقيقة، ثم إعطاء النموذج الفقرة أو القسم الأكبر الذي تنتمي إليه ليرى السياق كاملاً.

[term metadata-filtering]
name = التصفية بالبيانات الوصفية
def = تضييق البحث بخصائص المستند كالتاريخ أو القسم أو اللغة، مثل البحث في سياسات عام 2026 فقط.

[term knowledge-base]
name = قاعدة المعرفة
def = مجموعة المستندات والمعلومات المنظمة التي يعتمد عليها نظام RAG أو المساعد للإجابة.

[term memory-systems]
name = أنظمة الذاكرة
def = آليات تجعل النموذج «يتذكر» معلومات بين المحادثات أو داخل المهام الطويلة، لأن النموذج نفسه لا يتذكر شيئاً بعد انتهاء المحادثة.

[term short-term-memory]
name = الذاكرة قصيرة المدى
def = ما يبقى في نافذة السياق أثناء المحادثة الحالية فقط، ويضيع بانتهائها.

[term long-term-memory]
name = الذاكرة طويلة المدى
def = معلومات تُحفظ خارج النموذج (في قاعدة بيانات) وتُسترجع في محادثات لاحقة، مثل تفضيلات المستخدم.

[term conversation-memory]
name = ذاكرة المحادثة
def = حفظ سجل المحادثة أو ملخصه حتى يفهم النموذج الإشارات للرسائل السابقة مثل «كما قلتَ قبل قليل».

desc = الانتقال من مجرد الإجابة على الأسئلة إلى أنظمة مستقلة تخطط، تستخدم الأدوات، وتتعاون لإنجاز مهام معقدة.
simple = الوكيل نموذج لغوي أُعطي أدوات وهدفاً. بدل أن يجيب مرة واحدة، يخطط للمهمة، ويختار أداة (بحث، تشغيل كود، إرسال طلب)، ويقرأ النتيجة، ويقرر الخطوة التالية، ويكرر حتى ينجز الهدف. وبروتوكول MCP معيار مفتوح يسمح بربط أي أداة بأي نموذج بطريقة موحدة.
analogy = الفرق بين موسوعة ومساعد شخصي: الموسوعة تجيبك عندما تسألها، أما المساعد فيأخذ المهمة «احجز لي موعداً» ويتصل ويقارن ويحجز ويعود إليك بالنتيجة.
why = الوكلاء يقومون بأفعال حقيقية، لذلك أخطاؤهم أخطر من أخطاء النموذج العادي. وكيل يقرأ بريدك يمكن أن يُخدع برسالة تحتوي أوامر مخفية (حقن الأوامر).
example = وكيل برمجي يُعطى وصف خطأ في التطبيق، فيقرأ الكود، ويكتب الإصلاح، ويشغّل الاختبارات، ويعدّل حتى تنجح، ثم يرسل التغيير للمراجعة.

[pkg 09]
name = تحسين الاستدلال والتشغيل
desc = التقنيات الهندسية التي تجعل النماذج اللغوية العملاقة تعمل بأقصى سرعة وأقل استهلاك للذاكرة وتكلفة السيرفرات.
simple = تشغيل نموذج ضخم مكلف: يحتاج كروت شاشة (GPU) بذاكرة كبيرة، وكل كلمة يولدها تستهلك حسابات. هذه الحزمة عن جعل التشغيل أسرع وأرخص: تصغير النموذج بالتكميم، وتخزين الحسابات المتكررة، وخدمة عدة مستخدمين معاً بذكاء. أدوات مثل Ollama وllama.cpp تسمح بتشغيل نماذج كاملة على حاسوبك الشخصي.

example = نموذج يحتاج 140 جيجابايت من الذاكرة بدقته الكاملة يمكن تكميمه إلى نحو 40 جيجابايت ليعمل على جهاز واحد بدل عدة خوادم.
