[stage s1]
title = Mga Batayan
lead = Ang pundasyon ng lahat ng binuo sa AI: ang wika ng matematika na pinagsusulatan ng mga algorithm, ang mga patakaran ng machine learning, ang istruktura ng malalalim na neural network, at ang mga tool at data engineering na nagpapakain sa kanila.
simple = Hindi "nag-iisip" ang AI tulad natin. Software ito na natututo mula sa mga halimbawa sa halip na isulat ng tao ang bawat patakaran. Para matuto, kailangan nito ng tatlong bagay: wika ng matematika para ilarawan ang data, paraan para sukatin at itama ang sarili nitong mga mali, at magandang data na mapag-aaralan. Ang yugtong ito ang bumubuo sa tatlong iyon.
analogy = Parang pag-aaral magmaneho. Ang matematika ang physics ng paggalaw, ang machine learning ang pagpa-practice sa parking lot habang may nagtatama sa iyo, at ang data ang mga oras na nasa likod ka ng manibela. Walang silbi ang pagsasaulo ng mga patakaran kung kulang ang oras ng practice.
why = Lahat ng susunod sa atlas na ito, mula ChatGPT hanggang AI agents, ay nakatayo sa mga ideyang ito. Kapag naiintindihan mo ang mga batayan, maiintindihan mo kung bakit minsan nagkakamali ang isang model at kung bakit ang masamang data ay nagbubunga ng masamang model.
example = Ang spam filter ng email mo. Walang sumulat ng patakaran para sa bawat pekeng email. Natutunan ng sistema kung ano ang hitsura ng spam mula sa milyon-milyong email na may label na.

[pkg 00]
name = Matematikal na Batayan
desc = Ang pundasyon para maintindihan kung paano gumagana ang mga algorithm sa loob. Kung wala ito, imposibleng basahin ang mga research paper o intindihin ang pag-train ng mga model.
simple = Hindi nakikita ng computer ang larawan o pangungusap. Ang nakikita nito ay mga numerong nakaayos sa mga talahanayan (matrix). Ang linear algebra ang nagtatakda kung paano iniimbak at pinaparami ang mga numerong iyon, ang calculus ang nagsasabi kung saang direksyon babaguhin ang mga ito para bumaba ang error, at ang probability ang nagpapahintulot sa model na sabihing "90% sigurado ako" sa halip na oo o hindi lang.
analogy = Ang gradient descent ay parang pagbaba sa bundok sa makapal na hamog. Hindi mo kita ang lambak, pero ramdam mo ang lupa sa ilalim ng paa mo, kaya laging sa pinakamatarik na pababa ka humahakbang hanggang marating mo ang pinakamababang punto.
example = Kapag tinatantya ng map app ang oras ng pagdating mo, kinakalkula nito ang posibilidad ng traffic batay sa nakaraang data, hindi gamit ang isang nakapirming patakaran.

[term 00.4]

[term 00.5]

[pkg 01]
name = Mga Batayan ng Machine Learning
desc = Ang paraan na nagpapahintulot sa computer na humugot ng mga pattern at matuto mula sa data nang hindi isinusulat ang bawat hakbang.
simple = Sa tradisyonal na programming, isinusulat natin ang mga patakaran, ibinibigay ang data, at nakukuha ang resulta. Sa machine learning, ibinibigay natin ang data kasama ang mga tamang sagot, at ang model mismo ang tumutuklas ng mga patakaran. Ang pinakamalaking panganib ay kabisaduhin nito ang mga halimbawa sa training sa halip na matutunan ang pattern, kaya pumapalpak ito sa anumang bagong kaso.
analogy = Ang estudyanteng nagsasaulo ng mga sagot sa mga lumang exam ay papasa lang sa mga exam na iyon, at babagsak kapag nagbago ang mga tanong. Iyan ang overfitting. Kaya itinatago natin ang bahagi ng data (ang test set) at sinusubok ang model sa mga tanong na hindi pa nito nakikita.
example = Natutukoy ng mga bangko ang kahina-hinalang transaksyon gamit ang model na tinrain sa milyon-milyong transaksyong may label na "lehitimo" o "panloloko". Iyan ang supervised learning.

[pkg 02]
name = Deep Learning
desc = Mga arkitektura ng neural network na maraming layer, na kusang natututo ng palalim nang palalim na representasyon ng masalimuot na data.
simple = Ang neural network ay binubuo ng mga layer ng simpleng digital na "neuron". Bawat layer ay kumukuha ng output ng nauna at humuhugot ng mas malalim na pattern: sa isang larawan, gilid ang nakikita ng unang layer, hugis ang sumunod, at mukha na ang mas malalalim. Kapag nagkamali ang network, bumabalik ang error mula dulo pasimula (backpropagation) at bahagyang inaayos ng bawat layer ang mga weight nito.
analogy = Parang assembly line: bawat manggagawa ay nagdadagdag ng maliit na bahagi, at kapag may lumabas na sirang produkto, may supervisor na naglalakad pabalik sa linya at sinasabi sa bawat isa kung gaano siya nakaambag sa depekto para maayos niya ang trabaho niya.
example = Ang face unlock ng telepono mo ay gumagamit ng convolutional neural network (CNN) na ginagawang numerical na fingerprint ang mukha mo at ikinukumpara ito sa nakaimbak.

[term 02.0]
name = Artificial Neural Networks
def = Mga computational graph ng magkakaugnay na node na hango sa mga biological na neuron at nakaayos sa sunud-sunod na layer.

[term 02.1]
name = Perceptron
def = Ang pinakabatayang yunit ng neural network: kinukuwenta ang linear na kombinasyon ng mga input at dinadaan ito sa activation threshold.

[term 02.2]
name = Multi-Layer Perceptron
def = Feedforward network na may mga hidden layer, kayang mag-model ng anumang masalimuot na non-linear na function.

[term 02.3]
name = Forward Propagation
def = Ang pagdaloy ng input data sa mga layer at activation ng network para makuha ang huling output.

[term 02.4]
name = Backpropagation
def = Algorithm na bumabaybay pabalik sa network at kinukuwenta, gamit ang chain rule, ang gradient ng loss para sa bawat parameter.

[term 02.5]
name = Activation Functions
def = Mga non-linear na transformation sa kabuuan ng bawat neuron na nagpapahintulot sa network na matuto ng mga non-linear na pattern.

[term 02.6]
name = ReLU
def = Rectified Linear Unit; ibinabalik ang max(0, x), binabawasan ang problema ng nawawalang gradient at mabilis kalkulahin.

[term 02.7]
name = Sigmoid
def = Hugis-S na function na nagdadala ng anumang halaga sa [0, 1]; karaniwan sa pagbibigay ng probability sa binary classification.

[term 02.8]
name = Tanh
def = Hyperbolic tangent; dinadala ang mga input sa [-1, 1] na nakasentro sa zero, kaya mas balanse ang gradient descent.

[term 02.9]
name = GELU
def = Gaussian Error Linear Unit; probabilistic na activation function na standard sa mga modernong Transformer tulad ng BERT at GPT.

[term 02.10]
name = Batch Normalization
def = Teknik na nino-normalize ang mga activation ng bawat mini-batch para patatagin at pabilisin ang training.

[term dropout]
name = Dropout
def = Random na pagpatay sa bahagi ng mga neuron habang nagte-train, para hindi umasa ang network sa iisang neuron at matuto ng mas pangkalahatang pattern sa halip na magsaulo.

[term weight-init]
name = Weight Initialization
def = Pagpili ng panimulang halaga ng mga weight bago mag-train. Ang masamang simula ay puwedeng magpabagal nang husto sa training o pigilan itong umusad.

[term lr-scheduler]
name = Learning Rate Scheduler
def = Pagbabago ng learning rate habang nagte-train, kadalasang malalaking hakbang sa simula at maliliit at tumpak sa dulo.

[term transfer-learning]
name = Transfer Learning
def = Pagkuha ng model na tinrain sa malaking gawain at paggamit nito bilang panimula sa bago, kaya mas kaunting data at oras ang kailangan.

[term optimizers]
name = Optimizers: SGD, Adam, AdamW
def = Ang mga paraan na nagpapasya kung paano inaayos ang mga weight pagkatapos kalkulahin ang error. Pinakasimple ang SGD, awtomatikong inaayos ng Adam ang laki ng hakbang ng bawat weight, at ang bersyon nitong AdamW ang pinakakaraniwang pagpipilian sa pag-train ng language model ngayon.

[term batch]
name = Batch
def = Maliit na grupo ng mga halimbawa na sabay na pinoproseso ng model bago ang bawat pag-update ng weight, sa halip na isa-isa o lahat nang sabay.

[term epoch]
name = Epoch
def = Isang buong pagdaan ng model sa buong training dataset. Karaniwang ilang epoch ang training.

[term cnn]
name = CNN (Convolutional Neural Network)
def = Mga network na ginawa para sa larawan na nagpapadaan ng maliit na window sa larawan para matukoy ang mga gilid, hugis at pattern. Sila ang nagpasimula ng rebolusyon sa computer vision.

[term rnn]
name = RNN (Recurrent Neural Network)
def = Mga network na nagpoproseso ng sequence nang hakbang-hakbang habang may dalang "memorya" ng nauna. Ginamit ito sa teksto at pananalita bago ang Transformer.

[term lstm]
name = LSTM (Long Short-Term Memory)
def = Uri ng recurrent network na may mga "gate" na nagpapasya kung ano ang itatabi at kakalimutan, kaya naaalala nito ang impormasyon mula sa simula ng mahabang sequence.

[term gru]
name = GRU (Gated Recurrent Unit)
def = Mas simple at mas mabilis na bersyon ng LSTM na may mas kaunting gate at katulad na performance sa maraming gawain.

[term autoencoder]
name = Autoencoder
def = Network na natututong i-compress ang data sa maliit na representasyon at saka buuin itong muli. Ginagamit ito sa pagtukoy ng anomalya, tulad ng transaksyong hindi mabuo nang maayos ng model dahil kakaiba ito.

Ang mga library tulad ng PyTorch ang humahawak sa mabibigat na kalkulasyon sa mga graphics card, at ang mga platform tulad ng Hugging Face ay may libu-libong handa nang model. example = Ang startup na gustong magkaroon ng model na nakakaintindi ng Taglish ay hindi kailangang gumastos ng milyon-milyong dolyar para mag-train mula sa simula. Puwede itong kumuha ng open model at i-fine-tune ito gamit ang QLoRA sa iisang makina.

[pkg 04]

[stage s2]
title = Malalaking Modelo ng Wika (LLM)
lead = Ang puso ng generative revolution: ang attention ng Transformer, ang pre-training ng mga foundation model, mga sistema ng context at RAG, mga AI agent, at ang pagpapabilis ng kanilang pagtakbo.
simple = Ang mga language model tulad ng ChatGPT at Claude ay gumagana, sa kaibuturan, sa isang nakakagulat na simpleng ideya: hulaan ang susunod na salita. Hinahati nila ang teksto sa maliliit na piraso, gumagamit ng mekanismong tinatawag na "attention" para piliin kung aling naunang salita ang mahalaga sa kasalukuyan, at pinipili ang pinaka-malamang na piraso. Kapag ang napakalaking model ay tinrain sa napakaraming teksto, lumilitaw mula sa simpleng paghulang iyon ang mga kakayahang mukhang pag-unawa: pagsasalin, pagbubuod, pag-code.
analogy = Parang larong pagkumpleto ng pangungusap: "Pumunta ako sa panaderya para bumili ng…" Hula mo ay "pandesal" dahil marami ka nang nabasa at narinig na ganitong pangungusap. Ganoon din ang ginagawa ng model, pero nabasa na nito ang katumbas ng milyon-milyong libro.
why = Nasa lahat ng dako na ang mga model na ito: search, edukasyon, customer service, programming. Kapag alam mo kung paano sila gumagana, alam mo kung kailan magtitiwala sa sagot at kung kailan ito susuriin, at kung bakit puwede silang mag-"hallucinate" ng impormasyon nang buong kumpiyansa.
example = Kapag nagmumungkahi ang keyboard ng telepono mo ng susunod na salita habang nagta-type ka, napakaliit na language model iyon na gumagana sa parehong prinsipyo.

[pkg 05]
name = Arkitektura ng Transformer
desc = Ang rebolusyonaryong self-attention architecture na pumalit sa mga recurrent network at nagbukas ng daan sa modernong generative AI.
simple = Bago ang Transformer, binabasa ng mga model ang teksto nang salita-por-salita at nakakalimutan ang simula ng mahahabang pangungusap. Binabasa ng Transformer ang buong pangungusap nang sabay, at pinapayagan ng "attention" ang bawat salita na tingnan ang lahat ng iba pa at piliin kung alin ang mahalaga sa kanya. Kaya naiintindihan nito na ang "siya" sa dulo ng talata ay tumutukoy sa taong nabanggit sa simula.
analogy = Parang mambabasang may highlighter: sa bawat salita, hina-highlight niya ang ibang salita sa teksto na nakakatulong para maintindihan ito, mas matingkad ang ilan kaysa sa iba.
example = Sa "Hindi magkasya ang maleta sa kotse dahil masyado itong malaki," ang attention ang nagpapahintulot sa model na iugnay ang "ito" sa maleta at hindi sa kotse.

[term 05.1]
name = Tokens

[term 05.2]

[term 05.3]

[term 05.5]
