ارفع محتوى هذا المجلد كما هو إلى جذر الاستضافة (public_html أو ما يعادله):
  index.html            الصفحة الرئيسية (كل الشعارات مضمنة داخلها)
  assets/favicon.svg    أيقونة المتصفح (تتبدل تلقائياً مع الوضع الداكن)
  assets/icon-192.png   أيقونة أندرويد
  assets/apple-touch-icon.png  أيقونة آيفون/آيباد عند الإضافة للشاشة الرئيسية
  assets/og-cover.png   الصورة التي تظهر عند مشاركة الرابط في فيسبوك وواتساب

بدون اختيار، يتبع الموقع وضع جهاز الزائر (فاتح ← عاجي، داكن ← داكن).
